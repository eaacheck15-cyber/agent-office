# 🛡️ Закрытый контейнер с SOCKS5-пулом для офиса агентов

Изолированный Docker-контейнер: весь сетевой выход агентов офиса наружу — **только через SOCKS5-прокси из пула**. Прямого доступа к интернету из клиентов нет.

## Как это работает

```
Агент офиса  →  127.0.0.1:1080 (ротатор в контейнере)  →  SOCKS5-прокси из пула  →  интернет
```

- **stream_pool.py** — потоковая добыча прокси. Не ждёт валидации всей очереди:
  прокси добавляются в пул **параллельно, по мере проверки** (100 воркеров).
- **rotator.py** — SOCKS5-ротатор: на каждый запрос берёт следующий живой прокси (round-robin),
  при отказе перебирает до 5 прокси (failover).
- **Сид-пул**: на старте грузятся ранее проверенные прокси (seed/*.json) — мгновенный старт без ожидания сети.

## Потоки обновления (всегда свежие)

| Параметр | Значение | Что делает |
|---|---|---|
| `FETCH_EVERY` | 300 c | перезапуск добычи списков прокси (GitHub + API) |
| `PERSIST_EVERY` | 10 c | запись пула в файл (ротатор видит свежих) |
| `REAP_EVERY` | 300 c | перепроверка пула, мёртвые убираются |
| `POOL_RELOAD` | 5 c | ротатор перечитывает пул |
| `WORKERS` | 100 | параллельных валидаторов |
| `PROXY_TIMEOUT` | 6 c | таймаут на один прокси |
| `FAILOVER` | 5 | попыток прокси на один запрос клиента |

## Изоляция

- Порты наружу: `127.0.0.1:1080` (SOCKS5) и `127.0.0.1:8912` (статус пула) — только localhost
- `--cap-drop ALL`, `no-new-privileges`, не privileged
- Сеть: bridge (не host), доступ наружу есть только у самого контейнера для добычи прокси
- Внутри контейнера (для агентов) прямого доступа в интернет нет — только через ротатор

## Запуск

```bash
cd office/container && ./run.sh
# или
docker compose up -d --build
```

## Проверка

```bash
# статус пула
curl http://127.0.0.1:8912/status

# внешний IP через ротатор (меняется на каждом запросе)
curl -x socks5://127.0.0.1:1080 https://api.ipify.org

# ротация: 10 запросов → 10 разных IP
for i in $(seq 10); do curl -s -x socks5://127.0.0.1:1080 https://api.ipify.org; echo; done
```

## Использование агентами офиса

Любой агент/инструмент может ходить в сеть только через ротатор:
```bash
export ALL_PROXY=socks5://127.0.0.1:1080
export HTTP_PROXY=socks5://127.0.0.1:1080
export HTTPS_PROXY=socks5://127.0.0.1:1080
```
