## 1. ABET Global — инфраструктурные слабости (средние)

| Находка | Детали |
|---|---|
| Отсутствуют security-заголовки | нет CSP, HSTS, X-Content-Type-Options, Referrer-Policy (nikto) |
| BREACH-кандидат | Content-Encoding: deflate |
| TRACE разрешён | OPTIONS, TRACE, GET, HEAD, POST |
| Слабый SPF | `~all` (softfail) + include:outbound.mailhop.org (AWS 52.x/54.x может слать почту) |
| MT5-сервер открыт | mt5api:443 — MT5-трейдинг без видимой изоляции |
| Всё на одном сервере | сайт + CRM + почта + MT5 + API = единая точка отказа (108.181.154.20) |
